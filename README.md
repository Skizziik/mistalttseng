# 🎧 English Trainer — голосовой тренажёр английского

Одностраничный голосовой ассистент для изучения английских слов (уровень A2+).
Говоришь с ним голосом, он гоняет тебя по словам, поправляет ошибки и помнит твой
прогресс с интервальным повторением. Мозг — **Mistral**, голос — **локальный XTTS-v2**
на твоей видеокарте, слух — встроенное распознавание речи браузера.

## Как это работает

```
┌─ Браузер (GitHub Pages, HTTPS) ────────────────────────┐
│  🎤 распознавание речи (Web Speech API, хендс-фри)       │
│  🧠 Mistral large  ──► api.mistral.ai (напрямую, CORS)   │
│  🔊 озвучка        ──► http://localhost:8020 (твой ПК)   │
│  💾 память слов     ──► localStorage (интервалы Лейтнера) │
└─────────────────────────────────────────────────────────┘
                              │
                  ┌───────────▼────────────┐
                  │ Локальный XTTS-сервер   │
                  │ Python + RTX 4060       │
                  │ server/xtts_server.py   │
                  └─────────────────────────┘
```

Голос работает **только** через локальный XTTS — фолбэков нет (так и задумано).
Пока локальный сервер не запущен, тренажёр честно скажет об этом.

## Запуск

### 1. Локальный голос (XTTS-v2) — на твоём ПК

Нужен **Python 3.10 или 3.11** ([python.org](https://www.python.org/downloads/), при установке отметь *Add to PATH*).

```bat
cd server
run.bat
```

Первый запуск:
- создаст виртуальное окружение `.venv`;
- поставит PyTorch с CUDA 12.1 (под RTX 4060);
- поставит XTTS (`coqui-tts`) и Flask;
- скачает модель XTTS-v2 (~1.8 ГБ, потом кешируется).

Когда увидишь `Сервер слушает http://localhost:8020` — голос готов. Оставь это окно открытым.

> Если CUDA не подхватилась — сервер всё равно поднимется на CPU, но будет медленно.
> Проверь, что стоят свежие драйверы NVIDIA.

### 2. Ключ Mistral

Получи ключ на [console.mistral.ai](https://console.mistral.ai). На сайте тренажёра
открой ⚙ **Настройки** → вставь ключ. Он хранится **только в твоём браузере**
(localStorage) и в репозиторий не попадает.

### 3. Открой тренажёр

- **Локально:** просто открой `index.html`… *нет* — для микрофона нужен https или localhost.
  Запусти простой сервер из корня проекта:
  ```bat
  python -m http.server 5500
  ```
  и открой `http://localhost:5500`.
- **Онлайн:** через GitHub Pages (см. ниже) — `https://skizziik.github.io/mistalttseng/`.

В настройках проверь, что адрес локального голоса = `http://localhost:8020` и горит
«✓ голос на связи». Выбери диктора, нажми **тест**. Затем — **Начать диалог**.

## Деплой на GitHub Pages

Репозиторий: `https://github.com/Skizziik/mistalttseng`

1. Запушь содержимое в ветку `main`.
2. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch**,
   ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет на `https://skizziik.github.io/mistalttseng/`.

> Сайт по HTTPS обращается к `http://localhost:8020`. Браузер считает localhost
> безопасным, а сервер отдаёт заголовок `Access-Control-Allow-Private-Network: true`,
> поэтому запрос проходит. Нужен Chrome или Edge.

## Как пользоваться

1. Запусти локальный голос (`server/run.bat`).
2. Открой сайт, вставь ключ Mistral, проверь голос.
3. Жми **Начать диалог** — дальше всё голосом, без кнопок:
   - ассистент спрашивает «как будет по-английски …?»;
   - ты отвечаешь голосом по-английски;
   - правильно — похвалит и даст следующее; неправильно — скажет верный вариант и
     коротко разберёт, что значило сказанное тобой слово;
   - можно и просто поболтать — он ответит и вернётся к слову.
4. **Стоп** — пауза.

### Память и повторение
- Слова, которые знаешь, уходят на всё более длинные интервалы (1 мин → 10 мин → 1 ч → 6 ч → 1 д → 3 д → 7 д).
- Ошибочные возвращаются скоро и ещё раз переспрашиваются внутри сессии.
- Новые слова подбирает ИИ на разные бытовые темы (долю новых слов настраиваешь ползунком).
- Бэкап памяти: ⚙ Настройки → **Экспорт / Импорт**.

## Структура

```
index.html          интерфейс
styles.css          стили
app.js              диалоговый цикл и связка всего
js/
  config.js         настройки (localStorage)
  prompts.js        системный промпт и директивы для Mistral
  mistral.js        вызовы Mistral API
  tts.js            клиент локального XTTS (разбивка ru/en, проигрывание)
  stt.js            распознавание речи (Web Speech API)
  memory.js         интервальное повторение + статистика
server/
  xtts_server.py    локальный XTTS-сервер (Flask, CORS + Private Network Access)
  requirements.txt
  run.bat           установка и запуск под Windows
```

## Настройки голоса
- **Диктор:** список встроенных голосов XTTS (один и тот же голос говорит и по-русски, и по-английски).
- **Язык микрофона:** по умолчанию `en-US` (ответы словами по-английски). Хочешь болтать по-русски — переключи на `ru-RU`.
